# Guide d’utilisation de Lecture

Lecture vous aide à lire en français et en anglais : vous suivez votre progression, surlignez les passages
importants, cherchez les mots inconnus et révisez ensuite votre vocabulaire.

## 1. Ajouter des livres

- Cliquez sur **« + Ajouter un livre »**, ou glissez vos fichiers dans la bibliothèque.
- Formats acceptés : **PDF**, **EPUB** et **TXT** (les TXT sont convertis pour profiter de toutes les fonctions).
- La langue du livre est détectée automatiquement. Si elle est fausse ou inconnue (**?**), corrigez-la avec le
  petit menu **FR / EN** sous la couverture : c’est elle qui détermine la langue des définitions.

> ⚠️ Les PDF **scannés** (pages photographiées, sans texte sélectionnable) ne peuvent pas être lus.
> Astuce : si vous ne pouvez pas sélectionner un mot dans votre lecteur PDF habituel, le PDF est scanné.

Des livres libres de droits : [Project Gutenberg](https://www.gutenberg.org/) (anglais),
[Gallica](https://gallica.bnf.fr/) et [Ebooks libres et gratuits](https://www.ebooksgratuits.com/) (français).

## 2. Lire

| Action                     | Comment                                                                                                   |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| Page suivante / précédente | Flèches **→ ←** du clavier, boutons **‹ ›** sur les côtés, ou glisser sur écran tactile                   |
| Aller à un chapitre        | **☰ Sommaire**                                                                                           |
| Changer l’apparence        | **Aa Réglages** : thème clair / sépia / sombre ; police, taille, interligne et marges (EPUB) ; zoom (PDF) |
| Revenir à la bibliothèque  | **← Bibliothèque**                                                                                        |

Votre position est enregistrée à chaque page : à la prochaine ouverture, la lecture reprend au même endroit.
Le pourcentage lu et le temps de lecture apparaissent sous chaque couverture.

## 3. Surligner et annoter

1. Sélectionnez un passage : un menu apparaît.
2. Choisissez une couleur (jaune, vert, rose, bleu).
3. Cliquez plus tard sur le surlignage pour **changer sa couleur**, **ajouter une note** (Ctrl+Entrée pour
   enregistrer) ou le **supprimer**.

Le bouton **✎ Surlignages** liste tous les passages du livre, dans l’ordre de lecture : filtrez par couleur,
cliquez pour y revenir, ou **exportez-les en Markdown**.

## 4. Comprendre un mot

- **Double-cliquez sur un mot** : le dictionnaire s’ouvre à côté du texte (en bas sur téléphone).
  - Livre en anglais → définition en anglais + traduction en français.
  - Livre en français → définition en français + traduction en anglais.
- Les mots conjugués ou au pluriel sont reconnus : _décida_ → **décider**, _ran_ → **run**, _yeux_ → **œil**.
- 🔊 fait entendre la prononciation quand elle est disponible.
- Pour un **passage entier**, sélectionnez-le puis choisissez **« Traduire »** dans le menu.

Les mots déjà cherchés restent disponibles **hors ligne**. La traduction des passages dépend d’un service
gratuit limité à quelques milliers de caractères par jour.

## 5. Apprendre son vocabulaire

1. Dans le dictionnaire, cliquez sur **« ☆ Ajouter au vocabulaire »**. Le mot est enregistré avec sa traduction,
   sa définition et **la phrase du livre** où vous l’avez rencontré.
2. La page **Vocabulaire** liste vos mots : recherche, filtres par langue, livre et statut
   (_Nouveau_, _En cours_, _Acquis_).
3. La page **Révision** présente les mots à revoir sous forme de cartes :
   - **Espace** pour retourner la carte ;
   - **1** À revoir · **2** Difficile · **3** Bien · **4** Facile.

   Plus vous connaissez un mot, plus il revient tard (demain, dans 3 jours, dans 2 semaines…) : c’est la
   **répétition espacée**. Le nombre de mots à réviser s’affiche à côté de « Révision ».

4. **« Exporter pour Anki »** crée un fichier à importer dans [Anki](https://apps.ankiweb.net/)
   (Fichier › Importer).

## 6. Sauvegarder ses données

Vos livres et vos données sont stockés **uniquement dans ce navigateur**. Dans **Paramètres** :

- **Télécharger une sauvegarde** : un fichier contenant tout (livres compris). Faites-le régulièrement.
- **Restaurer une sauvegarde** : sur le même ou un autre appareil ; les données présentes sont conservées et
  complétées.
- **Protéger mes données** : demande au navigateur de ne jamais effacer les données de Lecture pour libérer de
  la place.

> ⚠️ Vider les données de navigation du site efface vos livres. Gardez une sauvegarde récente.

## 7. Installer l’application et lire hors ligne

Dans Chrome ou Edge, cliquez sur l’icône **Installer** dans la barre d’adresse (sur téléphone : menu ›
_Ajouter à l’écran d’accueil_). Lecture s’ouvre alors comme une application et fonctionne **sans connexion**
(sauf la recherche de nouveaux mots). Quand une nouvelle version est disponible, un bandeau propose de mettre
à jour.

## 8. Langue de l’interface

**Paramètres › Interface** : français ou anglais. Par défaut, la langue de votre navigateur est utilisée.

## Raccourcis clavier

| Touche              | Action                                        |
| ------------------- | --------------------------------------------- |
| → / Page suivante   | Page suivante                                 |
| ← / Page précédente | Page précédente                               |
| Échap               | Fermer le menu, le panneau ou le dictionnaire |
| Ctrl + Entrée       | Enregistrer une note                          |
| Espace              | Retourner une carte de révision               |
| 1 à 4               | Répondre à une carte de révision              |
